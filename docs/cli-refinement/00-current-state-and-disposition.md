# Current State and Final Disposition

> Temporary audit input. The implementation workstreams are authoritative for how to change each item.

## Rating vocabulary

- **KEEP** — behavior is real and appropriately represented; make only contract/grouping updates.
- **OVERHAUL** — underlying capability is useful, but its wiring, naming, safety, output, or UX is incomplete.
- **REMOVE** — delete the public behavior now; do not preserve it as a functioning alias.
- **HIDE** — retain for an internal caller or compatibility window, but omit from common help and canonical user docs.
